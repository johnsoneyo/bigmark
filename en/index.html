What We Do

Cloud Platforms

We set up infrastructure on AWS, Azure and GCP with Terraform, lower your monthly cloud bill and migrate services between providers, for example from Azure to GCP.

Kubernetes

Production Kubernetes on EKS, AKS and GKE: we write Helm charts, move services off old VMs into the cluster, set up logging and monitoring, and track down faults when production misbehaves.

DevOps & CI/CD

Pipelines for build, test and deployment with GitHub Actions or Jenkins, including migrating grown Jenkins setups to GitHub Actions.

Java Backend & Architecture

We build services with Java, Spring Boot and RabbitMQ, and refactor older Spring applications so they run cleanly in containers.

Our Approach

  1. Context

    We find out where your team stands, what runs in production and where it hurts, by talking to the people who build and run it.

  2. Scope

    We agree on which topics we take on, how we fit into your workflow, and whether we work on a time-and-materials basis or on a defined scope. If something isn’t a fit for us, we’ll say so.

  3. Working together

    We work directly in your repositories, document as we go and share what we know day to day, so your team stays in control of the systems.
